PaddleOCR (PP-OCRv4)

            
Best for low-power edge devices and microcontrollers where GPU compute is completely unavailable. Good character recognition, but cannot preserve complex tables or perform key-value extraction.

          

          

            
Consumer GPU (RTX 3050 6GB)

            
GLM-OCR 2 (0.9B)

            
Fits easily inside 2.4GB VRAM. Delivers state-of-the-art markdown tables, reading order preservation, and cursive handwriting detection with zero hallucination.

          

          

            
Structured Key-Value Only

            
Numind/NuExtract

            
Specialized schema-following extractor. High precision and recall on key-value extraction, deterministic output ($T=0$), and zero chat hallucination.

The 4-Step Hybrid Pipeline

            
OpenCV Booster + GLM-OCR 2 + NuExtract (Pagewise) + NuExtract (Verification). Highest accuracy (98.2%), lowest CER (1.8%), highest verified field F1 (97.9%), zero hallucinations.
